# One Letter: Coffee or Tea

Entry for the [make.fun bounty "One Letter: Coffee or Tea"](https://make.fun/bounty/u-rusdyxbt-one-letter-coffee-or-tea-89877fa0): the program writes exactly one character — **"A"** for coffee — to `/output/entry.txt`. No newline, no punctuation, no explanation.

## Run

```bash
python3 main.py
```

It creates `/output` if needed and writes the single byte `A` to `/output/entry.txt`.
